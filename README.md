# SHEETORA (شيتورا) - منصة قوالب Excel والخدمات الرقمية للأعمال

> **شغلك أذكى مع شيتورا**  
> المنصة المتخصصة لرواد الأعمال والشركات في مصر والوطن العربي لتوفير قوالب Excel معتمدة، خدمات تحليل البيانات المتقدمة، وبرمجة الأنظمة الرقمية المخصصة.

---

## 1. نظرة عامة على المعمارية التقنية (Architecture)

تم بناء المنصة بالكامل لتكون جاهزة للإنتاج، مع مراعاة أعلى معايير الأمان وقواعد الفصل بين الأدوار:
- **الواجهة الأمامية (Frontend):** React 19 + TypeScript + Vite + Tailwind CSS + React Router.
- **التصميم وتجربة المستخدم (UI/UX):** تصميم عربي أصيل يدعم RTL افتراضياً، خطوط Cairo الرسمية، ونظام ألوان مستوحى من هوية شيتورا (الأخضر الزمردي `#126B45` والزيتي الداكن `#0B3527` والبيج الدافئ `#F8FAF7`) مع الالتزام بقواعد Zero-Pill وعدم استخدام أرقام أو تقييمات وهمية.
- **قاعدة البيانات والتخزين (Backend & Storage):** Supabase PostgreSQL مع 21 جدولاً، سياسات أمان مشددة على مستوى الصفوف (Row Level Security - RLS)، ومستودعات تخزين مشفرة.
- **معالجة التنزيلات المصرح بها (Authorized Downloads):** روابط تحميل موقعة مؤقتة (Signed URLs) بصلاحية 60 ثانية للملفات بعد التحقق الخادمي من أحقية المستخدم (سواء كان قالباً مجانياً أو مدفوعاً بطلب مسدد).
- **بوابة الدفع (Payment Gateway Abstraction):** طبقة وسيطة مجهزة للتعامل بالجنيه المصري (EGP) مع Paymob وميزة والمحافظ الرقمية، مع عدم محاكاة أي عملية دفع وهمية عند غياب المفاتيح.

## 2. خطوات الإعداد والتشغيل السحابي (Supabase Setup)

### الخطوة الأولى: إنشاء مشروع Supabase
1. سجل الدخول إلى [Supabase Console](https://supabase.com).
2. أنشئ مشروعاً جديداً (New Project) واختر أقرب منطقة جغرافية (مثل Frankfurt / eu-central-1).
3. احتفظ بكلمة مرور قاعدة البيانات.

### الخطوة الثانية: تنفيذ ملفات الـ SQL Migrations
انتقل إلى قسم **SQL Editor** في لوحة Supabase، ونفذ الملفات التالية بالترتيب:

1. **`supabase/migrations/20261020000000_sheetora_schema.sql`**
   - ينشئ الـ 21 جدولاً الكاملة (`profiles`, `user_roles`, `categories`, `templates`, `orders`, `service_requests`, `ad_campaigns` وغيرها) مع المفاتيح والفهارس والقيود الرياضية.
2. **`supabase/migrations/20261020000001_sheetora_rls_policies.sql`**
   - يفعّل سياسات الـ RLS لمنع وصول غير المصرح لهم، ويضبط دوال الصلاحيات والـ Triggers التلقائية للمستخدمين الجدد.
3. **`supabase/migrations/20261020000002_sheetora_storage_and_seed.sql`**
   - ينشئ مستودعات التخزين السحابية (`sheetora-files` خاص، `sheetora-previews` عام) ويحقن التصنيفات والقوالب المعتمدة الأولية.

### الخطوة الثالثة: تعيين أول مدير للنظام بأمان (Configuring the First Admin)
لمنع أي استغلال، لا يمكن تعيين المدير من خلال استمارة التسجيل العامة. لترقية أول حساب إلى مدير:
1. أنشئ حساباً بالبريد الإلكتروني من واجهة الموقع `/auth/register` (مثلاً: `admin@sheetora.com`).
2. في **SQL Editor** بـ Supabase، شغّل الأمر الآمن التالي:
   ```sql
   SELECT public.promote_user_to_admin('admin@sheetora.com');
   ```
3. سيتم إسناد دور `admin` فورياً في جدول `user_roles`.

## 3. إعداد متغيرات البيئة (Environment Variables)

قم بإنشاء ملف `.env` في المجلد الرئيسي بناءً على `.env.example`:

```env
# رابط ومفتاح الوصول العام لـ Supabase (Settings -> API)
VITE_SUPABASE_URL="https://your-project-ref.supabase.co"
VITE_SUPABASE_PUBLISHABLE_KEY="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

# مفاتيح بوابة الدفع Paymob EGP (اختياري - عند تفعيل المدفوعات الحية)
VITE_PAYMOB_API_KEY=""
VITE_PAYMOB_INTEGRATION_ID=""
VITE_PAYMOB_IFRAME_ID=""

# خدمة البريد الإلكتروني للإشعارات (Resend / SMTP)
VITE_RESEND_API_KEY=""
```

*ملاحظة: إذا لم تقم بتزويد مفاتيح Supabase بعد، سيعمل التطبيق تلقائياً في وضع المعاينة الآمن (Local Demo Mode) متضمناً شريط التحكم العلوي لتبديل الأدوار واختبار كل الوظائف.*

## 5. سيناريوهات الاختبار والتحقق (Testing Checklist)

1. **التحميل المجاني (Free Downloads):**
   - انتقل إلى `/templates`، اختر قالباً مجانياً مثل *"نموذج التوقع المالي وحركة التدفقات النقدية"*.
   - تأكد من تسجيل الدخول (يتطلب النظام حساباً موثقاً لمنع الروبوتات).
   - اضغط *"تحميل مجاني"* وسيبدأ تنزيل الملف مباشرة ويتم تسجيله في `/account/downloads`.

2. **التراخيص المدفوعة والدفع (Paid Downloads & Checkout):**
   - اختر قالباً مدفوعاً مثل *"مسير رواتب الشركات المتكامل"* (299 ج.م).
   - أضفه للسلة أو توجه مباشرة إلى `/checkout`.
   - يوضح النظام أن بوابة الدفع الإلكتروني تلتزم بالمفاتيح الحقيقية، أو يمكنك إتمام الشراء عبر *"التحويل البنكي"* وتصدر الفاتورة بحالة `pending`.
   - كمدير في `/admin/orders`، يمكنك فحص الفاتورة وتأكيدها بنقرة زر ليتاح للعميل التنزيل فوراً.

3. **طلب خدمة مخصصة وعرض السعر (Custom Services Workflow):**
   - انتقل إلى `/request-service`، املأ بيانات استشارة أو شيت مخصص.
   - استلم رقم المرجع الفوري (مثل `SR-2026-1042`).
   - افتح لوحة الإدارة في `/admin/requests`، وافق على الطلب واكتب عرض السعر ونطاق العمل.
   - في حساب العميل `/account/requests`، يظهر العرض الرسمي وإمكانية قبوله وبدء العمل.

4. **لوحة الإدارة والحماية من تصعيد الصلاحيات (Admin Access Isolation):**
   - حاول الدخول إلى `/admin` بحساب عميل عادي، ستظهر شاشة الرفض `403 Unauthorized`.
   - بدّل الدور من الشريط العلوي إلى *"مدير"* للوصول لكافة لوحات التحكم.
